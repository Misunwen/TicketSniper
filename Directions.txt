========================================
 TicketSniper 搶票狙擊手 - 使用說明
========================================

這是一套把「自動點擊搶票」與「地端 AI 驗證碼辨識」整合在一起的工具。
支援平台：拓元 tixcraft、KKTIX、ibon。
圖片只會傳到你自己的電腦（127.0.0.1），不會上傳到任何雲端。

----------------------------------------
 專案結構
----------------------------------------
TicketSniper/
├─ extension/          Chrome 擴充功能（眼睛 + 手）
│  ├─ manifest.json
│  ├─ content.js       自動點擊 + 驗證碼辨識主邏輯
│  ├─ background.js    讀取 / 觸發 Yii2 驗證碼 hash
│  ├─ popup.html/js    設定面板
│  └─ inject.min.js    ibon 專用橋接
├─ server/             OCR 伺服器（大腦）
│  ├─ app_en_tixcraft_V3.py   Flask 辨識主程式
│  ├─ models/          自訓練 ONNX 模型（tixcraft_tm / universal）
│  ├─ requirements.txt
│  └─ recognition_log.dat     辨識紀錄（執行後產生）
├─ launcher/           nodriver 啟動器（可選）
│  ├─ launcher.py      用 nodriver 開專用 Chrome 並導到活動頁
│  └─ config.json      設定（網址／profile／是否載入外掛…）
├─ tools/              輔助工具
│  └─ setup_deps.py    套件檢測＋自動安裝（安裝套件.bat 會呼叫）
├─ 啟動伺服器.bat      一鍵啟動 OCR 伺服器
├─ 啟動瀏覽器.bat      一鍵啟動 nodriver 瀏覽器（可選，含全自動流程）
├─ 安裝套件.bat        檢測所有套件，缺少就自動安裝
├─ 即時觀看紀錄.bat    即時看辨識紀錄
└─ 打包分享.bat        打包成 TicketSniper.zip（可帶去別台電腦）

----------------------------------------
 第零步：安裝套件（建議先做）
----------------------------------------
對「安裝套件.bat」點兩下：它會逐一檢查伺服器與啟動器需要的套件，
列出已安裝／缺少的項目，缺少的自動 pip install（含固定 ddddocr==1.5.6）。

----------------------------------------
 第一步：啟動伺服器（大腦）
----------------------------------------
1. 對「啟動伺服器.bat」點兩下。
2. 第一次會自動安裝 Python 套件，請耐心等待。
3. 看到類似「Running on http://127.0.0.1:5000」就代表成功。
4. 使用期間請保持這個黑色視窗開啟（縮小即可，不要關閉）。

若防毒軟體跳出警告，請選「允許存取 / 仍要執行」。

----------------------------------------
 第二步：安裝擴充功能（眼睛）
----------------------------------------
1. Chrome 網址列輸入：chrome://extensions/
2. 右上角開啟「開發人員模式」。
3. 點左上角「載入未封裝項目」，選擇本專案的「extension」資料夾。
4. 建議釘選到工具列。

----------------------------------------
 第三步：設定（點開擴充功能圖示）
----------------------------------------
【自動搶票】
- 自動勾選同意條款：建議長開。
- 售完自動重整：賣完時自動 F5，隨機等 5~15 秒。
- 自動選擇票數：1~4 張。
- 自動點擊指定區域／票價：開啟並填關鍵字。
- 區域關鍵字（分號＝備案，由左至右優先；同一段空白＝要同時符合）：
  例：VIP;1樓A區;特區;B區
  例：A區 週六   ← 名稱要同時包含「A區」和「週六」
  （關鍵字盡量精準、避免含票價或剩餘數量）
- 排除關鍵字：不想選到的字，例：輪椅;身障;視線不完整。
- 選區順序：由上而下（預設）／由下而上／取中間／隨機。
- 自動遞補：關鍵字都沒命中時，改成依「選區順序」挑一個。
- 提示音：搶到票或送出成功時發出音效。

【驗證碼辨識】
- 識別後自動填入輸入框：建議開啟。
- 開啟全自動模式：頁面載入 / F5 就自動辨識（搶票核心）。
- 使用 Yii2 hash 校正：拓元可修正單字元錯誤，建議開啟。
- ⚠️ 驗證碼填完後自動送出：預設關閉；開啟後會自動按「送出／下一步」，
  請自行評估風險（辨識錯誤也可能送出）。
- 伺服器網址：預設 http://127.0.0.1:5000。
- 輸入模式：逐字模擬（安全）或瞬間帶入（快）。
- 驗證碼長度：拓元通常為 4。
- 重試次數：辨識長度不符時最多換圖重試次數。

----------------------------------------
 第四步（可選）：用 nodriver 啟動瀏覽器（全自動）
----------------------------------------
雙擊「啟動瀏覽器.bat」即可，它會自動完成：
1. 檢查並安裝 OCR 伺服器套件，確認 ddddocr 版本為 1.5.6（自訓練模型需求）。
2. 啟動 OCR 伺服器，並等到 /health 就緒。
3. 自動下載並使用 Chrome for Testing（支援自動載入外掛，僅第一次下載）。
4. 用 nodriver 開專用設定檔、自動載入 extension、導到活動網址。

- 為何用 Chrome for Testing？Chrome 137+ 只在「品牌 Chrome」移除了
  命令列自動載入外掛；Chrome for Testing / Chromium 仍支援，所以能全自動。
- 若想改用系統原本的 Chrome：把 config.json 的 auto_download_chromium 設 false，
  啟動器會加 --disable-features=DisableLoadExtensionCommandLineSwitch 嘗試還原；
  若仍無效，請在設定檔手動載入一次外掛（開發人員模式 → 載入未封裝項目）。
- 其他 config.json 選項：
  * url：要開啟的活動網址。
  * server_url：OCR 伺服器網址（預設 http://127.0.0.1:5000）。
  * start_server：false 則不自動啟動伺服器。
  * browser_executable_path：指定瀏覽器執行檔（留空則用 Chrome for Testing）。

----------------------------------------
 操作小技巧
----------------------------------------
- 手動選擇驗證碼輸入框：若自動偵測不到，可用這個點選輸入框。
- F4：強制重新辨識一次驗證碼。
- 點一下驗證碼圖片：等新圖載入後自動重新辨識（需開啟全自動模式）。
- 想全自動：把「自動點擊 + 全自動模式 + 自動送出」都打開。

----------------------------------------
 分享到其他電腦
----------------------------------------
1. 對「打包分享.bat」點兩下，會產生 TicketSniper.zip。
   預設不含 Chrome for Testing（對方第一次啟動會自動下載）；
   若對方網路無法連 Google，打包時輸入 Y 可一起打包。
2. 對方解壓後依序執行：安裝套件.bat → 啟動瀏覽器.bat。
3. 對方需要：Windows + Python 3.10～3.12（pip 需可用）；第一次需網路。
4. ⚠ 切勿直接複製 chrome_profile（含登入/Cookies）；打包腳本已自動排除。

----------------------------------------
 常見問題
----------------------------------------
- 顯示無法連線：確認黑色伺服器視窗還在、網址是 127.0.0.1:5000。
- 讀不到 hash：該頁可能沒有 yiiCaptcha 外掛，通常不影響辨識。
- 改了程式沒生效：到 chrome://extensions/ 重新載入擴充功能，並重啟伺服器。
- 一次只開一個伺服器視窗，重複開啟會佔用同一個 port。
- 驗證碼不準：本專案使用自訓練模型，必須安裝 requirements 指定的
  「ddddocr==1.5.6」（1.6 版與模型不相容）。重新執行 安裝套件.bat 即可。
- 模型授權：server/models 內的模型來自 tickets_hunter 專案（GPL-3.0），
  詳見 server/models/NOTICE.txt。
