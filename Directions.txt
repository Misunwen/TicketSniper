========================================
 TicketSniper - 使用說明
========================================

這是一套把「自動點擊」與「地端 AI 驗證碼辨識」整合在一起的瀏覽器自動化工具。
圖片只會傳到你自己的電腦（127.0.0.1），不會上傳到任何雲端。

----------------------------------------
 專案結構
----------------------------------------
TicketSniper/
├─ extension/          Chrome 擴充功能（眼睛 + 手）
│  ├─ manifest.json
│  ├─ content.js       自動點擊 + 驗證碼辨識主邏輯
│  ├─ background.js    讀取 / 觸發 Yii2 驗證碼 hash
│  ├─ popup.html/js    設定面板
│  └─ inject.js        頁面橋接腳本
├─ server/             OCR 伺服器（大腦）
│  ├─ Flask 辨識主程式
│  ├─ models/          自訓練 ONNX 模型
│  ├─ requirements.txt
│  └─ recognition_log.dat     辨識紀錄（執行後產生）
├─ launcher/           nodriver 啟動器（可選）
│  ├─ launcher.py      用 nodriver 開專用 Chrome 並導到目標網址
│  ├─ control_server.py 本機 CDP 控制伺服器（受信任點擊）
│  └─ config.json      設定（網址／profile／是否載入外掛…）
├─ tools/              輔助工具
│  └─ setup_deps.py    套件檢測＋自動安裝（安裝套件.bat 會呼叫）
├─ 啟動伺服器.bat      一鍵啟動 OCR 伺服器
├─ 啟動瀏覽器.bat      一鍵啟動 nodriver 瀏覽器（可選，含全自動流程）
├─ 安裝套件.bat        檢測所有套件，缺少就自動安裝
├─ 即時觀看紀錄.bat    即時看辨識紀錄
└─ 打包分享.bat        打包成 TicketSniper.zip（可帶去別台電腦）

----------------------------------------
 第零步：安裝套件（建議先做）
----------------------------------------
對「安裝套件.bat」點兩下：它會逐一檢查伺服器與啟動器需要的套件，
列出已安裝／缺少的項目，缺少的自動 pip install（含固定 ddddocr==1.5.6）。

----------------------------------------
 第一步：啟動伺服器（大腦）
----------------------------------------
1. 對「啟動伺服器.bat」點兩下。
2. 第一次會自動安裝 Python 套件，請耐心等待。
3. 看到類似「Running on http://127.0.0.1:5000」就代表成功。
4. 使用期間請保持這個黑色視窗開啟（縮小即可，不要關閉）。

若防毒軟體跳出警告，請選「允許存取 / 仍要執行」。

----------------------------------------
 第二步：安裝擴充功能（眼睛）
----------------------------------------
1. Chrome 網址列輸入：chrome://extensions/
2. 右上角開啟「開發人員模式」。
3. 點左上角「載入未封裝項目」，選擇本專案的「extension」資料夾。
4. 建議釘選到工具列。

----------------------------------------
 第三步：設定（點開擴充功能圖示）
----------------------------------------
【自動操作】
- 自動勾選同意條款：建議長開。
- 售完自動重整：賣完時自動 F5，隨機等 5~15 秒。
- 自動選擇數量：1~4。
- 自動點擊指定區域／價格：開啟並填關鍵字。
- 區域關鍵字（分號＝備案，由左至右優先；同一段空白＝要同時符合）：
  例：VIP;1樓A區;特區;B區
  例：A區 週六   ← 名稱要同時包含「A區」和「週六」
  （關鍵字盡量精準、避免含價格或剩餘數量）
- 排除關鍵字：不想選到的字，例：輪椅;身障;視線不完整。
- 選區順序：由上而下（預設）／由下而上／取中間／隨機。
- 自動遞補：關鍵字都沒命中時，改成依「選區順序」挑一個。
- 提示音：成功時發出音效。

【驗證碼辨識】
- 識別後自動填入輸入框：建議開啟。
- 開啟全自動模式：頁面載入 / F5 就自動辨識（自動化核心）。
- 使用 Yii2 hash 校正：可修正單字元錯誤，建議開啟。
- ⚠️ 驗證碼填完後自動送出：預設關閉；開啟後會自動按「送出／下一步」，
  請自行評估風險（辨識錯誤也可能送出）。
- 伺服器網址：預設 http://127.0.0.1:5000。
- 輸入模式：逐字模擬（安全）或瞬間帶入（快）。
- 驗證碼長度：通常為 4。
- 重試次數：辨識長度不符時最多換圖重試次數。
- 【紀錄（回報用）】啟用除錯紀錄：開啟後記錄自動化過程（預設關）；
  按「匯出紀錄 (.txt)」可下載成文字檔回報（含版本、時間、網址與設定）；
  按「清除紀錄」可清空已累積的紀錄（不需重整）。

----------------------------------------
 第四步（可選）：用瀏覽器啟動器（全自動）
----------------------------------------
雙擊「啟動瀏覽器.bat」即可，它會自動完成：
1. 檢查並安裝 OCR 伺服器套件，確認 ddddocr 版本為 1.5.6（自訓練模型需求）。
2. 啟動 OCR 伺服器，並等到 /health 就緒。
3. 自動下載並使用 Chrome for Testing（支援自動載入外掛，僅第一次下載）。
4. 用 nodriver 開專用設定檔、自動載入 extension、導到目標網址。

⚠️ 每次啟動後請手動開啟「開發人員模式」：Chrome 把 `extensions.ui.developer_mode`
   列為受保護設定（有 MAC 簽章），**程式無法代為開啟**，只能手動。
   啟動後會自動開好 `chrome://extensions`，把**右上角「開發人員模式」切到開啟**即可。
   （這樣才能看到「重新載入」按鈕；外掛本身即使不開也會自動載入、正常運作。）

⚠️ 重要（IBON 平台）：IBON 的售票流程（Cloudflare + Queue-it）會**擋啟動器使用的
   Chrome for Testing / nodriver 環境**，出現「連線暫時受限 / Access Temporarily
   Restricted」。**要跑 IBON 請不要用這個啟動器**，改用：
     1) 執行「啟動伺服器.bat」（保持開啟）
     2) 用你平常的 Chrome → chrome://extensions → 開發人員模式 → 載入未封裝項目
        → 選本專案的 extension 資料夾
     3) 直接操作，不要開「啟動瀏覽器.bat」
   （實測：一般 Chrome + 外掛可正常選位；啟動器會被 IBON 擋。）

- 為何用 Chrome for Testing？Chrome 137+ 只在「品牌 Chrome」移除了
  命令列自動載入外掛；Chrome for Testing / Chromium 仍支援，所以能全自動。
- 若想改用系統原本的 Chrome：把 config.json 的 auto_download_chromium 設 false，
  啟動器會加 --disable-features=DisableLoadExtensionCommandLineSwitch 嘗試還原；
  若仍無效，請在設定檔手動載入一次外掛（開發人員模式 → 載入未封裝項目）。
- 其他 config.json 選項：
  * url：要開啟的目標網址（預設空白，請自行填入）。
  * server_url：OCR 伺服器網址（預設 http://127.0.0.1:5000）。
  * start_server：false 則不自動啟動伺服器。
  * browser_executable_path：指定瀏覽器執行檔（留空則用 Chrome for Testing）。
  * open_extensions_page：預設 true。啟動後自動開啟 chrome://extensions
    （開發人員模式會自動開啟，可直接按重新載入外掛）。
  * trusted_click：true（預設）時，點擊改用 CDP 受信任滑鼠事件（較不易被偵測）。
  * control_port：受信任點擊控制埠（預設 5100，僅綁定 127.0.0.1）。
  * block_trackers：預設 false。設 true 會封鎖分析／追蹤／側錄請求；但部分平台
    （如 IBON）會因缺少追蹤 beacon 而判定為機器人，請確認不影響後再開啟。
  * save_log：預設 true，會把啟動器輸出同步寫入 launcher/launcher_log.txt。
  * driver：預設 "zendriver"（nodriver 維護分支，stealth 較新）；可改 "nodriver"。
  * cf_auto_solve：預設 true。啟動器會定期偵測 Cloudflare 驗證頁並自動處理
    （以 CDP 穿透找 Turnstile checkbox 點擊，失敗才用內建 verify_cf）；失敗時請手動點一下。
  * overwrite_prefs：預設 true。啟動前把 profile 偏好寫成一般使用者樣貌（降低指紋）。
  * clean_profile：預設 true。啟動與關閉時清空瀏覽資料（cookie／快取／歷史／登入…），
    但保留擴充功能設定與開發人員模式狀態（popup 設定不流失）；每次啟動都是乾淨資料。
  * cookies / cookies_file：注入登入 cookie（讓瀏覽器帶已登入 session）。
    cookies 為 JSON 陣列，或 cookies_file 指向 JSON 檔（格式見 launcher/cookies.example.json）。
    例：cookies_file 設 "cookies.json"（請自行把範例複製成 cookies.json 並填入）。
  * ibon_auto：預設 false。設 true 時，launcher 以 CDP 受信任點擊自動操作 IBON 舊版
    .aspx（UTK0201）流程；此時請把擴充功能 popup 的「IBON 自動化」取消，避免重複。
  * ibon_area_keyword / ibon_exclude_keyword / ibon_fallback / ibon_ticket_count：
    IBON 的區域關鍵字（`;`／`,` 備案、空白＝AND）、排除字、找不到時遞補、購買張數。
  * ibon_auto_next：預設 true。IBON 數量頁設定好張數後自動按「下一步」。
  * ibon_spa_keyword / ibon_spa_query：新版 IBON SPA（closed Shadow DOM）用；
    以 CDP 穿透搜尋可點元素，`ibon_spa_keyword` 指定要點的文字（`;`／`,` 備案），
    `ibon_spa_query` 指定搜尋選擇器。未設定關鍵字時只記錄發現的元素，不會點擊。

----------------------------------------
 操作小技巧
----------------------------------------
- 手動選擇驗證碼輸入框：若自動偵測不到，可用這個點選輸入框。
- F4：強制重新辨識一次驗證碼。
- 點一下驗證碼圖片：等新圖載入後自動重新辨識（需開啟全自動模式）。
- 想全自動：把「自動點擊 + 全自動模式 + 自動送出」都打開。

----------------------------------------
 分享到其他電腦
----------------------------------------
1. 對「打包分享.bat」點兩下，會產生 TicketSniper.zip。
   預設不含 Chrome for Testing（對方第一次啟動會自動下載）；
   若對方網路無法連 Google，打包時輸入 Y 可一起打包。
2. 對方解壓後依序執行：安裝套件.bat → 啟動瀏覽器.bat。
3. 對方需要：Windows + Python 3.10～3.12（pip 需可用）；第一次需網路。
4. ⚠ 切勿直接複製 chrome_profile（含登入/Cookies）；打包腳本已自動排除。

----------------------------------------
 常見問題
----------------------------------------
- 顯示無法連線：確認黑色伺服器視窗還在、網址是 127.0.0.1:5000。
- 開發人員模式每次都要手動開？ 是。Chrome 把 `extensions.ui.developer_mode` 列為受保護設定
  （有 MAC 簽章），程式無法代為開啟；每次啟動後到自動開啟的 `chrome://extensions`，
  把右上角「開發人員模式」切到開啟即可（只是為了看到「重新載入」按鈕，外掛仍會自動載入）。
- 讀不到 hash：該頁可能沒有 yiiCaptcha 外掛，通常不影響辨識。
- 改了程式沒生效：到 chrome://extensions/ 重新載入擴充功能，並重啟伺服器。
- 一次只開一個伺服器視窗，重複開啟會佔用同一個 port。
- IBON 出現「連線暫時受限 / Access Temporarily Restricted」：這是 IBON 的 WAF
  （Cloudflare）擋「啟動瀏覽器.bat」所用的 CfT/nodriver 環境。請改用一般 Chrome +
  手動載入外掛（只跑 啟動伺服器.bat），不要用啟動器；並避免頻繁重整。
- 驗證碼不準：本專案使用自訓練模型，必須安裝 requirements 指定的
  「ddddocr==1.5.6」（1.6 版與模型不相容）。重新執行 安裝套件.bat 即可。
- 模型授權：server/models 內的模型來自第三方開源專案（GPL-3.0），
  詳見 server/models/NOTICE.txt。
